# 🎓 Udemy Clone Website

A front-end website inspired by Udemy, built using HTML5 and CSS3. This project recreates the look and feel of an online learning platform as part of my Full Stack Development learning journey.

## 🚀 Project Overview

The Udemy Clone is a front-end web development project designed to practice and demonstrate HTML and CSS skills through a real-world website layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Positioning
- Google Fonts
- Font Icons

## 💻 How to Run

1. Clone this repository:

   `git clone https://github.com/gideonrio/udemy-clone.git`

2. Open the project folder.
3. Open `index.html` in your browser.
